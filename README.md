# Network Traffic Controller  
A bandwidth limiting and traffic shaping tool using Python and Linux `tc` commands.

---

## Project Overview
This project allows you to control and limit network bandwidth on Linux systems.  
It provides commands to:
- Set bandwidth limit  
- Remove bandwidth limit  
- Check current traffic shaping status

Useful for:
- Network testing  
- Preventing bandwidth hogging  
- Simulating slow networks  
- Lab experiments and projects  


## Requirements
- Linux OS  
- Python 3.8 or higher  
- `tc` installed (usually pre-installed)
- Root privileges for setting bandwidth
